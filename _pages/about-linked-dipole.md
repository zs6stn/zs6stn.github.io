A linked dipole antenna is a versatile multi-band wire antenna that uses removable links or jumpers to switch between different lengths for different amateur radio bands. This design allows operators to use a single antenna across multiple HF bands without requiring an antenna tuner.

## What is a Linked Dipole?

The linked dipole is an excellent choice for ham radio operators who want:
- **Multi-band operation** - Work multiple HF bands with one antenna
- **No tuner required** - Each band segment is resonant
- **Simple construction** - Can be built with basic tools and materials
- **Portable design** - Perfect for field operations and portable stations

## How It Works

The antenna consists of wire segments connected by removable links (typically Anderson Powerpole connectors or similar). By adding or removing links, you change the overall length of the dipole to match different bands:

- All links installed = longest wavelength (e.g., 40m)
- Remove outer links = medium wavelength (e.g., 20m)
- Remove more links = shortest wavelength (e.g., 10m)
